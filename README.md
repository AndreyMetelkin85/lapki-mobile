# Android приложение учебного магазина Лапки

Покупательский клиент зоомагазина для ручного тестирования на Android. Работает с тем же API и данными, что веб-магазин. Оплата — симулятор, без реального списания денег.

## Возможности и логика

Каталог товаров и питомцев → карточка с фотографиями → гостевая корзина → вход и объединение корзин → контакты и адрес → общий заказ → тестовая оплата. Доступны поиск, фильтры, история и отмена заказов.

Используются готовые подтверждённые аккаунты. **Регистрации, восстановления пароля и административных экранов в приложении нет** — эти действия доступны в вебе и API.

Цены, остатки, резерв и статусы контролирует бэкенд. JWT хранится в SecureStore, гостевая корзина — отдельно для каждого сервера. Пароли и реквизиты карт не сохраняются. При потерянном ответе оплаты клиент сначала проверяет состояние заказа.

## Технологии и границы

React Native, TypeScript, Expo SDK 57, Expo Router, TanStack Query, Zod, SecureStore и AsyncStorage. Проверки — TypeScript, ESLint и unit-тесты.

- Здесь находятся Android-клиент, ресурсы, тесты и сборка APK.
- [Бэкенд](https://github.com/AndreyMetelkin85/swagger-petstore) содержит FastAPI, PostgreSQL, почту и общий Docker Compose.
- [Веб](https://github.com/AndreyMetelkin85/lapki-frontend) содержит браузерный магазин и администрирование.

## Установка для тестирования

1. Запустите общий стенд по [инструкции бэкенда](https://github.com/AndreyMetelkin85/swagger-petstore#первый-запуск-на-windows) либо из учебного архива.
2. В Android Studio запустите эмулятор **x86_64**.
3. Откройте http://localhost:8091, скачайте APK и перетащите файл на экран эмулятора.
4. Откройте «Лапки». Адрес API по умолчанию — `http://10.0.2.2:8080/api/v3`.

Docker-сервис `mobile` из образа `andymentor/lapki-mobile` только выдаёт APK. Само приложение работает в эмуляторе. Metro, Expo Go и сборка исходников для установки готового APK не нужны. Эта сборка не подходит для физических ARM-телефонов.

Другой API задаётся в **Аккаунт → Подключение**; смена сервера завершает сессию. `10.0.2.2` — адрес компьютера из стандартного Android Emulator, а не Docker-имя сервиса.

Готовый APK и контрольная сумма также есть в [релизе v0.1.3](https://github.com/AndreyMetelkin85/lapki-mobile/releases/tag/v0.1.3).

## Учебные доступы и оплата

Покупатель новой БД: `test@example.com`, пароль `password123`. Собственный аккаунт сначала зарегистрируйте и подтвердите через веб-магазин http://localhost:8090 и почту http://localhost:8025.

Карты: `4242424242424242` — успех; `4000000000000002` — отказ; `4000000000009995` — недостаточно средств. Месяц `12`, год `2099`, CVV `123`, имя `TEST USER`. Реальные реквизиты не используйте.

## Что изучать

Мобильную навигацию, формы, состояние сессии, корзину и восстановление действий после потери связи с API. У элементов есть семантические `testID` для будущих UI-автотестов; готовая мобильная UI-автоматизация пока не входит в проект.

## Разработка и проверки

Нужен Node.js 22.13+; локальная нативная сборка дополнительно требует JDK 17 и Android SDK.

```powershell
npm ci
npm run typecheck
npm run lint
npm test
```
