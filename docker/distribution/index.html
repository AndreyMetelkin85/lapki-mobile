Лапки — Android

Учебное приложение для эмулятора Android Studio x86_64.

Скачать APK

  1. Запустите Android-эмулятор в Android Studio.
  2. Скачайте APK и перетащите файл на экран эмулятора.
  3. Откройте приложение «Лапки».

Бэкенд должен работать на этом компьютере. Адрес в приложении: http://10.0.2.2:8080/api/v3.

Если порт API изменён, исправьте адрес в приложении: Аккаунт → Подключение.

Этот контейнер выдаёт установочный файл. Само приложение запускается в Android, не в Docker.

Для большинства физических телефонов нужна отдельная ARM-сборка. Это учебный APK с тестовой подписью, не версия для магазина приложений.
